# Public Repository Rules

This repository is public. All contributions must be safe for public release.

- Never commit secrets, credentials, tokens, API keys, or private configuration.
- Never publish private technical architecture or internal research details.
- Never publish internal research-system codenames.
- Never make unsupported public claims.
- Do not perform implementation work directly on `main`.
- All implementation changes require pull-request review before merge.
- Production deployment requires explicit Founder approval.
